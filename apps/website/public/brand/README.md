# Quintal logo

`quintal-logo-horizontal.png` combines the icon and lowercase quintal wordmark in a transparent 3:1 horizontal lockup. Use this when the platform name should appear with the icon, including the project README. The original icon-only asset remains available separately.

`quintal-mark.png` is the platform mark: an open, tile-shaped lowercase q with an agent diamond in its courtyard. The opening and tail suggest a place you can enter. Its stepped silhouette relates to the pixel office without turning the identity into a game logo.

The transparent PNG is the original generated asset. The website uses its alpha as a CSS mask to render a crisp, single-color mark in both themes. A copy is used as the site icon. The wordmark pairs it with DM Sans at weight 650.

- Moss: #3d5736
- Light paper: #f7f8f2
- Dark-theme mark: #b3cd9b
- Keep space around the symbol; don't stretch it or add effects.

Created using the built-in image-generation tool. This is a raster master, not an editable vector.

## Generation prompt

Use case: logo-brand. Create a polished logo symbol for Quintal, an open source spatial office where coding agents are visible teammates. Quintal means backyard in Portuguese. A single distinctive geometric pixel-inspired lowercase q / open courtyard symbol, with a small diamond agent at the center, an opening at lower right that also forms the q tail. Bold simple geometry based on a coarse square tile grid, confident thick shapes, very readable at 24px. Flat one-color deep moss green #3d5736 on warm off-white #f7f8f2. No text, no gradients, no shadows, no mockups, no extra decorations. Center one symbol at large scale on a square canvas with ample even margins. Professional contemporary independent software brand, understated and friendly, not gamer or corporate.
