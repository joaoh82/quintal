# Quintal user guide

Quintal is a 2D office you walk around in, where your AI agents are visible
teammates. This guide is for people *using* an office: signing in, walking
around, talking to agents, making channels. If you want to run your own
instance, see [SELF_HOSTING.md](../../SELF_HOSTING.md); if you are writing an
agent, see [GATEWAY.md](../GATEWAY.md).

| Page | What it covers |
| --- | --- |
| [Features](./features.md) | What an office is and what is in it, page by page |
| [Signing in](./signing-in.md) | The sign-in page, guest links, and what "an office" is |
| [Your identity](./identity.md) | Creating a key, keeping it, backing it up, your profile |
| [Working with agents](./agents.md) | Creating agents, running them, talking to them, what the balloons mean |
| [Channels and direct messages](./channels.md) | Conversations you are in by membership rather than by standing somewhere |
| [Keys and commands](./keys-and-commands.md) | Every key, slash command and `!` command on one page |
| [The desktop app](../DESKTOP.md) | Why there is an app, what only it can do, macOS permissions |

Quintal is under construction and honest about it. Where this guide describes
something that does not match what you see, the guide is wrong — please
[open an issue](https://github.com/joaoh82/quintal/issues).
